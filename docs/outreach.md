# Outreach

BarelyReal should grow from real users and real interest only. Do not buy,
trade, automate, or fake GitHub stars.

## Short Ask

```text
I published BarelyReal, an MIT-licensed macOS/Windows keyboard, mouse,
clipboard, and file-sharing utility. It is early alpha, but there are public
builds for both platforms and a security-focused roadmap. If this kind of tool
is useful to you, feedback or a GitHub star would help me prioritize the work:
https://github.com/greendexd/BarelyReal
```

## Where To Share

- Friends who use both macOS and Windows daily.
- Developer chats where local productivity tools are relevant.
- Swift, .NET, Windows desktop, and macOS utility communities.
- Security-minded developers who can review pairing and transport design.

## What To Ask For

- Does the project solve a real workflow?
- Does the README explain the risk of dev-mode transports clearly?
- Which platform should be hardened first?
- Would they test a signed/notarized build when available?
